Introduction

An API defines how software components communicate. A web API exposes that contract over HTTP: clients send requests, servers return responses, and both sides depend on documented behavior.

This guide introduces REST architecture alongside practical HTTP API conventions. A JSON endpoint alone does not establish that an API satisfies every REST constraint. Treat the architectural model and everyday implementation choices as related but distinct subjects.

A reference you can revisit

Start with the fundamentals, follow a request through its response, then examine security, evolution, and errors. Examples use a fictional projects API and reserved example domains.
