Code examples

These are original illustrative excerpts for a fictional API. No endpoint runs here, and api.example.com is not this project's API. Selected HTTP/1.1 headers are shown; framing and transport details are omitted.

Read rather than execute

The examples teach request intent, media types, and response shape. They do not establish authentication, validation, storage, or a production contract.

GET a collection

In this sample contract, a subsequent request would send the continuation as a cursor query parameter while keeping compatible filters. The server defines the cursor; clients should treat it as opaque.

POST a resource

The server assigned the identifier in this illustration. Credentials are omitted because access policy is not defined for this fictional exchange. Real APIs must document and enforce their access requirements.

API error response

errors is a custom extension in this example, not a predefined RFC 9457 field. Problem type and instance URIs are illustrative; do not treat them as hosted documentation. The instance identifies this occurrence, not necessarily the requested resource.
